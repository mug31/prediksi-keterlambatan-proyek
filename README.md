# Prediksi Probabilitas Keterlambatan Proyek Multi Sumber Daya Terbatas

Kode simulasi, data sintetis, dan skrip analisis untuk naskah:

> Kusbianto, M., Majid, M. N. G., Andriansyah, R. A., & Yaqin, M. A. *Prediksi Probabilitas Keterlambatan
> Proyek Multi Sumber Daya Terbatas*. Diajukan ke Jurnal Pustaka Data.

*English summary: code, synthetic data, and analysis scripts for a study that predicts the probability of
schedule delay in resource-constrained multi-project portfolios. Training data are generated by Monte Carlo
simulation of eight sub-projects extracted from Project Management Plan (PMP) documents. Logistic Regression,
Random Forest, Gradient Boosting, and an MLP are compared with leave-one-subproject-out validation, with an
emphasis on probability calibration (Brier score, ECE, calibration intercept and slope).*

## Isi repositori

```
06_simulasi_iterasi/            Pembangkitan data (subbab 2.1–2.3 naskah)
  data/                         Jadwal aktivitas, sumber daya, dan register risiko 8 subproyek (hasil ekstraksi PMP)
  simulasi_iterasi.py           Penjadwalan dengan antrian sumber daya + simulasi change request
  kalibrasi_risiko.py           Pemilihan faktor mitigasi f = 0,4 (dicocokkan ke analisis risiko PMP-08)
  buat_dataset_ml.py            Simulasi 1000 iterasi/subproyek, dipantau di 25/50/75% jadwal → dataset
  uji_dataset_ml.py             Uji kewajaran dan kebocoran label dataset
  dataset_ml/dataset_ml.csv     Dataset utama: 24.000 baris, 7 fitur, label Telat_Lebih_5_Persen
  dataset_ml/sensitivitas/      Dataset untuk faktor dampak 0,2 dan 1,0 (subbab 3.8)
  dataset_ml/README.md          Kamus variabel, rujukan parameter, dan karakteristik data
  hasil/                        Luaran simulasi per subproyek

04_implemen_desain_eksperimen/  Eksperimen dan analisis (subbab 2.4–3.8 naskah)
  experiment_pipeline.py        Model, kalibrasi Platt/Isotonic, validasi leave-one-subproject-out
  analisis_data.py              Selang kepercayaan bootstrap, uji hipotesis, ambang, deteksi dini
  bukti_pembahasan.py           Pemeriksaan pendukung pembahasan (transfer kalibrasi, alarm palsu, dll.)
  cek_nn_early_stopping.py      Pemeriksaan NN dengan early stopping (subbab 3.2)
  uji_pipeline.py, uji_analisis.py   Uji otomatis pipeline dan analisis
  hasil_eksperimen/, hasil_analisis/ Seluruh tabel CSV dan grafik yang dirujuk naskah

paper/gambar_paper.py           Menggambar Gambar 1–4 naskah dari CSV hasil
paper/gambar/                   Gambar 1–4 naskah
```

Nama folder mengikuti struktur kerja penelitian dan sengaja tidak diubah agar path antarskrip tetap sama
dengan versi yang menghasilkan naskah.

## Menjalankan ulang

Python 3.13 dan paket di `requirements.txt`.

```bash
pip install -r requirements.txt

# 1. Bangkitkan dataset (hasilnya identik dengan dataset_ml/dataset_ml.csv)
cd 06_simulasi_iterasi
python simulasi_iterasi.py
python kalibrasi_risiko.py
python buat_dataset_ml.py
python buat_dataset_ml.py --faktor-dampak 0.2 --keluaran dataset_ml/sensitivitas/dataset_ml_faktor_0.2.csv
python buat_dataset_ml.py --faktor-dampak 1.0 --keluaran dataset_ml/sensitivitas/dataset_ml_faktor_1.0.csv

# 2. Eksperimen dan analisis
cd ../04_implemen_desain_eksperimen
python experiment_pipeline.py --sensitivitas   # beberapa menit
python analisis_data.py                        # bootstrap; paling lama
python bukti_pembahasan.py
python cek_nn_early_stopping.py

# 3. Uji otomatis (opsional; --reproduksi menjalankan ulang pipeline dan membandingkan semua tabel)
python uji_pipeline.py --reproduksi
python uji_analisis.py

# 4. Gambar naskah
cd ../paper && python gambar_paper.py
```

Semua langkah memakai seed tetap, sehingga tabel yang dihasilkan sama dengan yang ada di repositori.

## Catatan data

- Seluruh data latih dan uji adalah **data sintetis** hasil simulasi, bukan catatan proyek nyata.
- Masukan simulasi (`06_simulasi_iterasi/data/`) diekstraksi dari delapan dokumen *Project Management Plan*
  portofolio Super ERP Farm Nation Enterprise 2026. Setiap baris mencantumkan bagian dokumen sumbernya di
  kolom `Sumber`, dan setiap tafsiran dicatat di kolom `Catatan`. Sumber daya ditulis per peran (mis. `PM1`,
  `BE1`), tanpa nama orang.
- Dokumen PMP aslinya tidak disertakan, sehingga `ekstraksi_pmp.py`, `ekstraksi_risiko.py`, dan uji ke-3 di
  `uji_dataset_ml.py` (pencocokan risiko dengan teks PMP) tidak dapat dijalankan dari repositori ini. Hasil
  ekstraksinya sudah tersedia di `data/`, sehingga langkah 1–4 di atas tetap dapat dijalankan.
- Komentar di kode memuat rujukan ke arahan pembimbing (mis. skenario change request `dosen`); nama tersebut
  adalah label skenario dan dibiarkan agar luaran tetap identik.
